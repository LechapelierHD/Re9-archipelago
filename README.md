# Re9 archipelago — client 1.0.121, apworld 1.0.7
Officially supported platform
  • Windows 10 / Windows 11 (64-bit)

What runs on Windows
  • "Re9 archipelago" launcher (install, YAML, updates)
  • In-game client (REFramework + Lua scripts)
  • REFramework (dinput8.dll) installed in the Steam game folder
  • Archipelago apworld (seed generation / hosting)
  • Automatic updates via the "Update" button

Windows requirements
  • Resident Evil Requiem owned/installed via Steam (AppID 3764200)
  • Archipelago 0.6.8 recommended (0.6.2 minimum) for hosting
  • Internet connection to join / host a room

Not supported (officially)
  • Native Linux
  • macOS
  • Consoles (PlayStation, Xbox, etc.)

Linux / Steam Deck (unofficial)
  • The Windows launcher does not run natively on Linux.
  • Playing through Proton / Wine is not guaranteed: REFramework and the
    client expect a Windows environment (dinput8 injection, paths, etc.).
  • No support or fixes are provided for Proton / Wine / Steam Deck.
  • If you try anyway: at your own risk, with no guarantee of Archipelago
    connectivity or stability.

Summary
  The mod is designed and tested for 64-bit Windows 10/11 only.
