# Re9 archipelago

Randomizer [Archipelago](https://archipelago.gg) pour **Resident Evil Requiem** (RE9).
Chaque objet ramassé devient un check partagé avec les autres joueurs du multimonde ; les objets
reçus arrivent dans le coffre des salles de sauvegarde.

## Télécharger

Va dans [Releases](../../releases/latest) et prends :

- **Re9-archipelago-X.Y.Z.zip** : le lanceur « Re9 archipelago » et le client en jeu ;
- **resident_evil_requiem.apworld** : le monde Archipelago (pour héberger ou générer une partie) ;
- **Resident.Evil.Requiem.yaml** : un exemple de réglages de joueur.

## Installer

1. Installe [REFramework](https://github.com/praydog/REFramework-nightly/releases) pour RE9.
2. Décompresse le zip où tu veux et lance `RE9.AP.Launcher.exe`.
3. Choisis **Rejoindre un multimonde** (ou **Héberger un multimonde**) et suis les étapes.
4. En jeu, ouvre le menu REFramework (Inser) et connecte-toi avant de ramasser quoi que ce soit.

Les mises à jour du client arrivent ensuite directement dans le lanceur (bandeau « Mise à jour
disponible » en haut, bouton **Mettre à jour**).
