# Resident Evil Requiem - installation

## Prérequis

- Resident Evil Requiem (Steam)
- [REFramework](https://github.com/praydog/REFramework-nightly/releases) pour RE9
- Archipelago 0.6.2 ou plus récent

## Générer une partie

1. Copier `resident_evil_requiem.apworld` dans `Archipelago\custom_worlds`.
2. Copier `Resident Evil Requiem.yaml` dans `Archipelago\Players` et le modifier
   (`game_difficulty` doit correspondre à la difficulté de la sauvegarde).
3. Générer et héberger la partie comme d'habitude.

## Jouer

1. Installer le client RE9 AP (mod REFramework) dans le dossier du jeu.
2. En jeu : touche **Insert**, fenêtre **Archipelago - Resident Evil Requiem**,
   renseigner le serveur et le nom du slot, puis connecter.
3. Chaque objet ramassé dans le monde envoie un check ; les objets reçus arrivent dans le coffre.
